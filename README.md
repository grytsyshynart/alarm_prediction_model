# Ukrainian Air Raid Sirens Forecaster (AI-Агент Прогнозування Тривог)

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![Zero Leakage](https://img.shields.io/badge/Data%20Leakage-Zero%20(L1%3D0.0)-brightgreen.svg)]()
[![Evaluation Protocol](https://img.shields.io/badge/Protocol-3R%20Framework-orange.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Автоматизована система машинного навчання для короткострокового (на завтра) та середньострокового (на 7 днів) прогнозування кількості повітряних тривог по регіонах України та на національному рівні.

Побудована за суворим науковим протоколом **3R (Repetitive, Rule-based, Return)** із **гарантією нульового витоку даних (Zero Data Leakage)**.

---

## 📌 Ключові можливості та архітектура

1. **Гарантія нульового витоку даних (Zero Data Leakage):**
   - Усі ознаки для дня $D$ розраховуються суто на базі подій $\le D-1$ через операцію `shift(1)`.
   - Вбудовано автоматичний змагальний стрес-тест (`leak_test.py`), який перевіряє, що будь-яке спотворення майбутнього не змінює вектори ознак минулого ($L_1\text{-diff} = 0.0$).
2. **Очищення від фрагментації (30-min Merge Gap):**
   - Повторні тривоги в межах однієї області з паузою $\le 30$ хвилин об'єднуються в один епізод. Емпірично доведено (турнір H25), що нормалізована похибка (NMAE) досягає глобального оптимуму саме при 30 хвилинах (0.3278).
3. **Нормалізація Scale-Free Ratio:**
   - Дерева рішень не прогнозують сирі кількості тривог (що призводить до краху при зміні тренду), а навчаються на відношенні $y / (\text{ew14} + 0.1)$ із вагою вибірки `sample_weight=base`.
4. **Оптимізація під метрику MAE:**
   - Використання `loss='absolute_error'` для прогнозування умовної медіани забезпечує надійну перевагу на лічильних перекошених даних.

## 🏆 Результати та 4 Чемпіонські Моделі

| Завдання | Фінальна архітектура | Dev (2023–25) $\Delta \text{MAE}$ | Test (2026) $\Delta \text{MAE}$ | Статус |
|---|---|---|---|---|
| **T1: Завтра по областях** | $\text{round}\left(\frac{\text{HGB}(\text{ratio}, \text{MAE}) \times \text{base} + \text{ew14}}{2}\right)$ | **$-4.5\%$** | **$-4.4\%$** | Статистично значущий виграш |
| **T2: Завтра по Україні** | Бейзлайн: ковзне середнє $\text{mean28}$ | — | — | Жодна складна ML-модель не перевершила бейзлайн |
| **T3: На 7 днів по областях** | Рівнозважений ансамбль: $\frac{\text{m28} + \text{ew7} + \text{ew14} + \text{ew28}}{4} \times 7$ | **$-3.8\%$** | **$-2.8\%$** | Стійкий до перенавчання |
| **T4: На 7 днів по Україні** | Ансамбль $\times 7$ + Історичний інтервал похибок (10%–90%) | **$-6.7\%$** | **$-1.8\%$** | Чесне 85% емпіричне покриття |

## 🚀 Швидкий старт

### 1. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 2. Завантаження датасету (якщо не завантажено)
```bash
python download_data.py
```

### 3. Перевірка відсутності витоку даних
```bash
python leak_test.py volunteer_data_en.csv
```

### 4. Генерація прогнозу на завтра та наступний тиждень
```bash
python alarm_forecaster.py --csv volunteer_data_en.csv
```
Результат буде виведено в термінал і збережено у файл `forecast_latest.csv`.

## 🧪 Наукові експерименти та турнір гіпотез

У проєкті реалізовано відтворювані скрипти перевірки гіпотез:
- `test_h25.py` / `test_h25_ext.py` / `run_h25_eval.py` — аналіз фрагментації та оптимізація вікна склеювання тривог.
- `test_h26.py` — бенчмарк 9 конфігурацій регіональної кластеризації (Тил vs Фронт).
- `test_h28.py` — тестування ефекту тактичних пауз після масованих ударів.
- `TOURNAMENT_REPORT.md` — повний звіт за протоколом 3R.
- `CONVERSATION_HISTORY.md` — детальна хронологія розробки проєкту з посиланнями на попередні обговорення.
